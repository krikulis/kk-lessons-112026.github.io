Tēma 3 — Pielikums (11:00–11:25)

Windows LAPS pārvaldība prasa tikai četras PowerShell komandas laboratorijā


# 1. Sagatavot Active Directory shēmu Windows LAPS
Update-LapsADSchema
# 2. Piešķirt darbstaciju OU tiesības saglabāt paroli AD
Set-LapsADComputerSelfPermission -Identity "OU=Workstations,DC=skola,DC=lv"
# 3. Iegūt unikālo lokālā admina paroli konkrētam datoram
Get-LapsADPassword -Identity "PC-LAB05" -AsPlainText
# Auditēts AD Event ID 4662 par katru paroles nolasīšanu
# Parole automātiski rotējas pēc politikas (piem., 30 dienas)
  • Paroles tiek šifrēti glabātas Active Directory un automātiski rotētas pēc lietošanas.
  • Tikai pilnvaroti IT administratori drīkst nolasīt konkrētas darbstacijas paroli ar žurnalēšanu.
  • Lielisks 30 minūšu laboratorijas darbs Windows Server modulī.
