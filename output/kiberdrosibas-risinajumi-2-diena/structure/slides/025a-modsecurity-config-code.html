Tēma 2 — Pielikums (09:45–10:10)

Sešas ModSecurity konfigurācijas rindas ieslēdz OWASP CRS aizsardzību laboratorijā


# /etc/nginx/modsec/modsecurity.conf
SecRuleEngine On
SecRequestBodyAccess On
SecAuditEngine RelevantOnly
SecAuditLog /var/log/nginx/modsec_audit.log
SecDefaultAction "phase:1,log,auditlog,deny,status:403"
Include /etc/nginx/modsec/crs-setup.conf
Include /etc/nginx/modsec/rules/*.conf
  • SecRuleEngine On pārslēdz WAF no novērošanas uz aktīvu uzbrukumu bloķēšanu.
  • SecAuditLog saglabā bloķēto HTTP pieprasījumu detaļas incidentu izmeklēšanai.
  • OWASP CRS nodrošina bezmaksas, kopienas uzturētas SQLi un XSS noteikumu kopas.
Pievērsiet uzmanību SecRuleEngine On — ja ražošanā tas paliek DetectionOnly, WAF tikai raksta žurnālus un neko nebloķē (tieši šo kļūdu redzēsim 4. tēmas Pakotnē A!).
