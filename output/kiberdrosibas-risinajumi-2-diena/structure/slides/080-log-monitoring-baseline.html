# Wazuh / rsyslog brīdinājumu bāzlīnija mazai IT komandai
alert_identity:
  - event_id: 4728   # Jauns lietotājs pievienots Domain Admins
alert_bruteforce:
  - source: fail2ban # >= 5 bloķētas SSH/VPN IP 10 minūtēs
  - source: modsec   # >= 10 HTTP 403 SQLi/XSS bloki 5 minūtēs
alert_integrity:
  - fim_watch: ["/etc/ufw/user.rules", "/etc/nginx/modsec/modsecurity.conf"]
  - notify: "security-alerts@organizacija.lv (tūlītēji)"
  • Iestatiet brīdinājumus par SSH/AD brutālo spēku, jaunu adminu pievienošanu un ugunsmūra izmaiņām.
  • Sekojiet arī WAF 403 pīķiem un DNS ugunsmūra bloķēto domēnu pieprasījumiem.
  • Pārbaudiet žurnālu servera brīvo diska vietu un MK Nr. 397 glabāšanas prasības.
Mazās organizācijās nav 24/7 SOC komandas, tāpēc 5–6 precīzi Wazuh vai Syslog e-pasta brīdinājumi sniedz milzīgu agrīnās atklāšanas vērtību.
