Tēma 2 (09:45–10:10)

„Viss, kas nav skaidri atļauts, ir aizliegts” ir vienīgā prognozējamā drošības politika

  • Noklusējuma aizliegums (Default Deny) bloķē neparedzētus portus un jaunus draudus.
  • Noklusējuma atļauja (Default Allow) liek bezgalīgi minēt un bloķēt riskus.
  • Eksplicīta DENY ALL + LOG rinda apakšā padara blokus redzamus žurnālos.

Divas pretējas filtrēšanas filozofijas

DEFAULT ALLOW (MELNAIS SARAKSTS)

Atļauj visu, bloķē tikai zināmos sliktos portus — jauni servisi kļūst tūlītēji atvērti

DEFAULT DENY (BALTAIS SARAKSTS)

Bloķē un logo visu (ufw default deny), atļauj tikai dokumentētus biznesa portus

Pat ja ugunsmūrim ir iebūvēts neredzams Implicit Deny, pievienojam skaidru DENY ALL + LOG rindu — tā nodrošina pierādījumus diagnostikai un incidentu analīzei.
