Tēma 3 (11:00–11:25)

Pieteikšanās ierobežošana un SSH atslēgas aptur automatizētu paroļu minēšanu


# /etc/ssh/sshd_config
PubkeyAuthentication yes
PasswordAuthentication no
PermitRootLogin no
ClientAliveInterval 300
ClientAliveCountMax 2
# /etc/fail2ban/jail.local
[sshd]
enabled = true
maxretry = 5
bantime = 15m
  • Iestatiet īslaicīgu konta bloķēšanu pēc 5 neveiksmīgiem mēģinājumiem (fail2ban / AD Lockout).
  • Linux serveros atslēdziet paroļu pieteikšanos, pieprasot tikai ed25519 SSH atslēgas.
  • Ierobežojiet neaktīvu sesiju ilgumu (ClientAliveInterval), lai pamesti termināļi aizvērtos.
Izskaidrojiet atšķirību starp brutālo spēku pret vienu kontu un „password spraying” (1 populāra parole pret 100 kontiem), ko palīdz pamanīt centralizēta žurnālu uzraudzība.
